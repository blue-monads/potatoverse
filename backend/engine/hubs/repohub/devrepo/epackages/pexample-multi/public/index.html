Example Multi Space Package

This package demonstrates multi-space organization in Potatoverse: a primary Main Space (non-default) and a secondary Sub-Space designated as the Default Space.

1. Main Space Concept

Every package has exactly one Main Space whose namespace matches the package slug (pexample-multi).

The package installer identifies this via MainSpaceId.

2. Default Space Flag

The default space is determined by is_default: true.

The default space does not need to be the main space. Here, the sub-space (pexample-multi:sub) is the default entrypoint.

3. Sub-Space Isolation

Sub-spaces use colon notation: pexample-multi:sub.

Each space retains its own server logic, execution sandbox, and assets directory.

Spaces in this Package

Namespace Space Role Default (is_default) Server File Serve Folder
pexample-multi Main Space No (false) server.lua public/
pexample-multi:sub Sub Space Yes (true) sub/server.lua sub/public/

Manifest Configuration (potato.json)

{
  "name": "Example Multi Space",
  "slug": "pexample-multi",
  "spaces": [
    {
      "namespace": "pexample-multi",
      "space_type": "App",
      "executor_type": "luaz",
      "server_file": "server.lua",
      "route_options": { "serve_folder": "public" },
      "is_default": false
    },
    {
      "namespace": "pexample-multi:sub",
      "space_type": "App",
      "executor_type": "luaz",
      "server_file": "sub/server.lua",
      "route_options": { "serve_folder": "sub/public" },
      "is_default": true
    }
  ]
}
