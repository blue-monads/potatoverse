Space Type: AppPlugin

Example Beta Plugin

This package is an AppPlugin designed to be plugged into host spaces (such as pexample-alpha).

Plugin Features:
  • Exports loader.js which gets concatenated into the host space's plugin_loaders.js.
  • Provides backend endpoints at /api/plugin/:space_key/pexample-beta/*.
  • Authenticates user claims against the host space via remote_ctx_token.
  • Can execute cross-space operations on the host space using the xRemote capability.
